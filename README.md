### 🔧 What I've built

**[PFMS: Predictive Facility Maintenance System](https://github.com/akoma-16/PFMS_MVC)**
Tells facility managers which equipment is likely to fail, before it breaks. An ASP.NET Core MVC app (EF Core code-first, SQL Server) calls a separate Python/Flask service that runs a Random Forest model trained on the AI4I 2020 industrial dataset.

| Accuracy | AUC | Services |
|:-:|:-:|:-:|
| **98.70%** | **0.9789** | **2** (.NET + Flask) |

**[StockGuard](https://github.com/akoma-16/StockGuard)** · *in progress*
Stock software for Nigerian pharmacies. Tracks drug expiry dates and enforces first-in, first-out dispensing so older stock sells before it expires. ASP.NET Core MVC, EF Core, SQLite, .NET 10.

**[Subtrak](https://github.com/akoma-16/Subtrak)** · *in progress*
A subscription tracker that puts every renewal on a calendar. Add a subscription and its billing cycle, then click any day to see what's due. Built in ASP.NET Core from a Figma design.

**Client websites**
- [Kanann](https://kanann.world): portfolio site for a model, coded from her Figma design and deployed on Vercel with a custom domain.
- Kindred: portfolio site for a model and stylist, with light and dark modes, filterable galleries and a lightbox. *In progress.*
